# Security Policy

This repository hosts a static personal portfolio.

## Reporting a security issue

Please report security or privacy issues privately by emailing **yaswanthkukkala123@gmail.com** with the subject `Portfolio Security Report`.

Include:

- The affected URL or file
- A concise description of the issue
- Safe reproduction steps
- Potential impact
- Any recommended remediation

Do not publish sensitive findings, personal data, credentials, or proof-of-concept material before coordinated disclosure.

## Scope

In scope:

- Content and code maintained in this repository
- The GitHub Pages deployment at `kalendra456.github.io/kalendra/`

Third-party platforms linked from the portfolio are governed by their own security policies and are not part of this repository's scope.
